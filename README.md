# Виджет банковских операций клиента
## Описание:
В проекте присутствую функции фильтрации банковских операций по дате и фильтрации транзакций по состоянию.
## Установка:
1. Клонируйте репозиторий
   ```
   git clone https://github.com/YuliyaSwan/Homework.git
   ```
2. Установите зависимости
   ```
   pip install -r requirements.txt
   ```
